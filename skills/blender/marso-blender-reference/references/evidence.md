# Reference evidence and measurements

Read this when the object is a real product, when its size or proportions matter, or when two references disagree. It adds to the landmark record; it does not replace the comparison.

## Rank the evidence

Use the highest-ranked source available for each fact, and record which source set it.

1. **Dimension drawings and published specifications.** Look for them first: the maker's support pages, a specifications tab, the last pages of a manual.
2. **Photographs and footage of the real object.** Step through footage frame by frame; it often holds closer views than the stills.
3. **Catalogue and promotional images.** They may be retouched or rendered, so use them for layout and finish, and confirm proportions against a higher rank.

If two sources disagree, the higher rank sets the proportion and the working record names the conflict. A reference the user supplied sets the design whatever its rank: if it conflicts with a published dimension, ask which wins. With nobody to answer, keep the user's design, use the published overall size and record the conflict.

## Fix the variant first

Name the exact variant, size and revision before measuring anything. An image that confirms the look does not confirm the size: read one proportion from both sources and check that they agree.

## Keep a dimension ledger

List every dimension the build uses in the working record:

| Dimension | Value | Basis | Source |
| --- | --- | --- | --- |
| Body width | 0.34 m | measured | maker's drawing |
| Overall height with handle | 0.21 m | nominal | specification table |
| Depth | 0.22 m | inferred | front photo only |

- Give units and the axis each value lies along.
- Keep body dimensions apart from overall bounds; handles, spouts and feet belong to the overall bounds.
- Treat a shipping or package size as the box, not the object.
- Treat a width read from a perspective photo as inferred, not measured.
- Mark every estimate as inferred, and build the model to its real evaluated bounds rather than scaling it afterwards to hit a nominal figure.

## Set image scale from two dimensions

When tracing sizes from a drawing or a level photo, set the scale from one known dimension. Then check a second known dimension that runs in the other direction. If the two scales differ by more than about 2%, the image is not a level view or was stretched: use a separate scale for each direction, or find another view.

## Inventory the features

List each feature the design is recognised by, with two facts:

- **Where it sits**, read from two views where the reference set has them. Check a part that is not symmetric against at least two photos.
- **How it meets the body:** flush, recessed, raised or blended. A part that looks bolted on usually has this wrong.

One front photo gives no depth. Record every depth taken from it as inferred.

Done when the working record holds the ledger with a basis for every dimension and the feature inventory.
