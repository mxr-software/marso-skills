# Complete a scene request

Use `marso-scene` when installed for a complete scene from photographs, a prompt or an existing layout. It owns stage coordination and completion. Discover it by name, not by an assumed sibling path.

If unavailable, preserve these essentials through verified tools: photographs supply observed inventory; prompts normally start with a Marso concept unless the design is settled or a direct blockout is requested. Generated new views are design proposals, not hidden-geometry evidence. Establish a coherent room shell and camera before detailed assets; ordinary wall corners default to 90 degrees unless supported otherwise. Inspect the blockout and continue unless the user requested approval or material ambiguity needs their answer.

Retain mixed asset routes, explicit model/generate intent, library reuse, relevant Studio project and one scene resource target. Do not manufacture detection IDs for prompt designs. Newly modelled assets need user geometry approval before Marso Retexture/PBR unless waived; blockout continuation is not that approval. Retexture proceeds directly to PBR, while accepted existing PBR assets keep their materials. Native jobs own monitoring; do not duplicate submissions on timeout.

Complete the requested scene with placed accepted assets, required materials, saved dependencies and lightweight review images. A graph, concept or placeholder layout is not a finished scene. Use the render/camera skills for requested final presentation work; no automatic film campaign. If a required specialist is absent, identify the gap and complete independent supported work rather than inventing its commands.
